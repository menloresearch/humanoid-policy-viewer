# Terrain tests

Generated by `scripts/make_terrain_benchmark.py`; see `docs/benchmarking.md#terrain-tests`. Each test's `"terrain"`
field names a fragment under `public/examples/scenes/terrain/` that is spliced into the default robot scene at run time.

| test | course |
|---|---|
| stairs_5cm / stairs_10cm | 5 steps up (35 cm treads), 1.5 m top, 5 steps down |
| slope_10deg / slope_15deg | ramp up to 0.3 / 0.4 m, 1.5 m top, ramp down |
| slope_push | the 10 degree course with lateral shoulder pushes (150 N climbing, 225 N descending) |
| obstacles | 14 scattered boxes, 3-7 cm high, 0.2-0.4 m footprint |
| rough | 0.3 m tiles, 0.5-4 cm high |

Every course starts 1.5 m in front of the spawn point, is 6 m wide and runs along +x; the robot is commanded to walk
forward at 0.4 m/s for 20 s.
